1.6. **Combined % на сделку** (наследие round 5 §1.5): из `engine._record_realized`
`pnl = c·[(px−pe)·s − f_x·px − f_e·pe]`, значит
`comb = 100·[(px−pe)·s − f_x·px − f_e·pe]/pe` — тождество, не требующее количества c.
Направление `s` из артефактов тем же методом round 5 (согласованность квантов в
многострочных позициях → знак филла → знак pnl; остаток неидентифицируемых строк —
консервативный минимум comb, верхняя добавка к средним оценивается и публикуется).
WR = доля строк с pnl > 0.

`report_p` харнесса (`net_pnl` в долларах, тот же страж издержек, что в правиле 5:
без funding и диагональных поправок). PASS = net_pnl ≥ 0 во всех фолдах; хотя бы
один фолд < 0 ⇒ FAIL, клетка мертва по правилу 6.** Клетка = класс×символ×TF

1.2. **carry_version** — значение из артефакта (хеш источника модуля + окно +
параметры, B-5); у каждого фолда своё значение (окно входит в хеш).

1.3. **n_settles** — засчитанные settlement-периоды строго внутри держания
(`entry_fill_ts < ts_j < exit_fill_ts`, крание не включаются — B-1.1.2).
**holds** — число удержаний (позиций) за фолд. **funding_gross ($)** —
`Σ +rate_j·notional_j` по засчитанным тактам; **friction ($)** — сумма
taker+slip трений на вход и на выход (фактические цены исполнения).
**net_pnl ($)** = funding_gross − friction (инвариант артефакта, проверен —
§1.8). **max_leg_dd_frac** — максимальная просадка ноги от entry_ref, доля
начального notional N₀ = capital (пессимизм по high 1m-бара, B устранённой
неоднозначности); **margin_call** (≥0.5·N₀) и **flat_fold** — флаги артефакта
(0/1).

1.4. **Годовая фолда:** `net$ / capital / (fold_days/365)` (B-1.1.5) — ровно
`annualized_pct` артефакта. **Дни фолда:** (end−start)/86400 = **111 суток**
каждый фолд (9 590 400 с), агрегат клетки **333 суток**.

1.5. **Агрегат клетки:** Σnet трёх фолдов; Σdays = 333; годовая =
`Σnet / capital / (Σdays/365)`; Σn_settles — для правила 1-аналога.

1.6. **Правило 1-аналог (пометка, не вердикт):** если Σn_settles по клетке < 30
— отдельная пометка в таблице. % и $ всегда рядом (методология к7-6).

1.7. **Формат:** $ округлены до 0.01, % до 0.01, max_leg_dd_frac до 0.0001 —
для читаемости; полная точность (Decimal, без потерь) — в `meas_rB_report.txt`
и артефактах. Округление не меняет знаков.

**Приложение. B-4 «Риски, которые прячем» — дословно из замороженного спека
(обязательное приложение к первому письму; текст спека, не анализ замерщика):**

- (a) basis-дрейф: высокий funding ≈ высокий basis перпа; вход шортом «дорого»,
  выход при нормализации — реальный PnL, который дельта-нейтральная модель
  обнуляет. Митигация после первого вердикта: read-only фетчер
  premiumIndex/mark-price (Binance), отдельная задача НЕ из этой ветки.

  slip/fee; трение короткой ноги на споте занижено вдвое (в реальности 4 ноги
  на круг) — фиксируется в письме константой «×2 трения» sensitivity-строкой.
- (c) кросс-venue: bars — Bybit, funding — Binance.
- (d) regime-shift: f2 уже показал +0.2%/год — селекция обязана пережить или
  серия умирает честно.
- (e) симуляция без реальных ордеров: риск биржи, капы, лимиты скорости — за
  рамками; оговорка в вердикте.

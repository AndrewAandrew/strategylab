1.5. **Combined % на сделку.** Из `engine._record_realized` (engine.py:184):
`pnl = c·[(px−pe)·s − f_x·px − f_e·pe]`, значит
`comb = 100·pnl/(c·pe) = 100·[(px−pe)·s − f_x·px − f_e·pe]/pe` — **тождество, не
требующее количества c**. `s` — направление; `f_e` = 0.0006 (J, профиль A S) / 0.0002
(S, B и TP1); `f_x` = taker для stop/market-филов, maker для take_profit. WR = доля
строк с pnl > 0 (для J тождественно доле comb > 0).

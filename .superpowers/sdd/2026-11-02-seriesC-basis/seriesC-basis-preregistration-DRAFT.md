## C-1. Контракт позиции

- Пара ног: лонг спота (полностьюcash, без плеча на ноге) + шорт USDT-метро перпа,
  both qty фиксированы на входе: `N₀ = capital·lev/(lev+1)` при lev=1, capital
  10 000 ⇒ **N₀ = 5 000$ на ногу**; `qty_spot = N₀/spot_ref`, `qty_perp = N₀/perp_ref`
  (не идентичны — residual-дельта = дрейф базиса, маркируем обе ноги отдельно).
- Направление торговли: **только контанго (b ≥ +θ_entry)** — шорт перпа получает
  carry и платит back. Экстремум b ≤ −θ требует шорта спота (borrow) — НЕ
  торгуется, фиксируется в вердикте как нереализованная ось (C-4a).
- Вход: последний закрытый тик `|b| ≥ θ_entry` (b>0) на `ts_d` ⇒ исполнение на
  `open` первого 1m-бара с `ts > ts_d` (оба venue, adverse: покупка спота по
  `open·(1+slip)`, шорт перпа по `open·(1−slip)`). Выход по сигналу: holding и
  `|b| ≤ θ_exit` ⇒ следующий open adverse. Принудительный выход: open последнего
  бара с `ts < fold_end`.
- Издержки: CostModel серии A, **4 ноги taker+slip** (первичная модель — taker,
  maker-sensitivity только по новому «ок» владельца, бюджет не позволяет ось).
- Carry: `funding_8h` начисление на короткую ногу строго внутри холда
  (`entry_fill_ts < ts_j < exit_fill_ts`), `+rate_j·qty_perp·mark_j`,
  `mark_j` = close последнего perp-бара `ts ≤ ts_j`.
- Маржа: `margin = N₀` (lev=1) на перп-ноге; просадка перпа по high ≥ 0.5·N₀ ⇒
  margin_call-клетка мертва; ≥ 1.0·N₀ ⇒ LIQUIDATED. Спот-нога cash — ликвидации
  нет, но просадка спота входит в equity холда полностью (нетто-маржа пары).

## C-1.1. Временные конвенции (зеркало B-1.1, заморожены)

1. Решение — только по закрытым тикам бэзиса (перп-бар и спот-бар одного ts);
   исполнение — open следующего бара, никакого заглядывания.
2. Начисления settlement — строго interior холда; выходного settlement в момент
   fill — не держался.
3. Маркировка — последние closes ≤ ts_j каждой ноги по своей базе.
4. Cash-flow фолда: Σ basis-PnL (вход/выход по исполнениям, Δb·N₀) + Σ carry −
   Σ трения 4 ног; всё в $ по ценам исполнения.
5. Годовая фолда: `net$/capital/(fold_days/365)`; агрегат клетки — Σ net / Σ дни.

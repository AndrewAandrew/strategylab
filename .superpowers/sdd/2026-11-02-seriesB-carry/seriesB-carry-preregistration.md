## B-0. Смена фундамента (почему это не раунд 8)

Серия A (7 раундов, 0 выживших) калибровала способ торговли intraday-ценовым
сигналом с gross-сдвигами осей ±0.1% против стены taker-круга 0.22%. Series B
меняет источник профита: процентный cash-flow фондинга против дельта-нейтральной
короткой ноги перпа. Прибыль не зависит от знака цены; трение — один вход+выход
на период удержания, а не 0.22% на каждую сделку.

## B-1. Контракт позиции

- Нога: шорт USDT-метро перпа, **qty фиксирована на входе** и равна
  `N₀ / entry_ref`, где `N₀ = lev·capital`, lev=1, capital=10 000 (старт каждого
  фолда, компаундинга внутри фолда нет — как в серии A).
- Вход: settlement-решение — по последнему отпечатанному rate: flat и `rate_i ≥ θ_entry`
  ⇒ исполнить на следующем баре. Выход по сигналу: holding и `rate_i < θ_exit`
  ⇒ исполнить на следующем баре. Выход принудительный: на open последнего 1m-бара
  с `ts < fold_end`.
- Издержки: CostModel серии A (taker 0.0006, slippage 0.0005). Исполнительная цена
  входа = `open·(1 − slip)` (шорт исполняется неблагоприятно нам), выхода = `open·(1 + slip)`; комиссия
  taker с фактической стоимости ноги. Цена хеджа (спотовая нога) = те же
  index-reference `open` без slip/fee — модельная оговорка B-4(b); нетто-цена сети
  в доллары НЕ входит (B-1 драфта), но трение с обеих сторон в них входит полностью.
- Маржа/риск ноги: см. устранённую неоднозначность B выше (пессимизм по high бара).

## B-1.1. Временные конвенции (заморожены)

1. Решение принимается ТОЛЬКО в моменты settlement из `funding_8h` (ts отсортированы);
   в момент `ts_i` наблюдаем `rate_i`; исполнение — `open` первого 1m-бара с `ts > ts_i`
   (никакого загляывания в будущие бары; если такого бара нет в окне — входа нет).
2. Фондинг засчитывается за settlement-такты строго внутри держания:
   `entry_fill_ts < ts_j < exit_fill_ts` (крайние не включаются: в `ts_i` решения мы
   ещё не держим; settlement ровно в момент исполнения принудительного выхода не
   держался).
3. Notional для начисления маркируется детерминированно:
   `notional_j = qty · mark_j`, `mark_j` = `close` последнего 1m-бара с `ts ≤ ts_j`
   (кросс-venue оговорка B-4(c)).
4. Cash-flow фолда: `+rate_j·notional_j` за каждый засчитанный `ts_j`;
   `−(taker+slip)`-трение на вход и на выход (фактическое по ценам исполнения).
5. Годовая фолда: `net$ / capital / (fold_days/365)`; агрегат клетки — по сумме net
   всех фолдов и суммарным дням.

## B-2. Правила выживания (доллар первичен — урок аменда 1)

Фолды серии A (f1/f2/f3, end exclusive), **holdout ts ≥ 1790294400 не читается**
(R-next-2). Пороги бою впервые, замораживаются ЭТИМ коммитом:

- **B2-1 (доллар, наследник правила 6):** каждый фолд каждой первичной клетки net ≥ $0.
  Хоть один фолд < $0 ⇒ FAIL, клетка мертва.
- **B2-2 (экономический смысл):** годовая net-доходность агрегата клетки ≥ **+3.0%/год**.
- **B2-3 (устойчивость):** каждый фолд даёт годовую > 0.
- **B2-4 (статистика):** bootstrap по дневным cash-flow (блоки 30 дней, iid по блокам,
  1000 ресэмплов, seed=42, перцентильный 95% ДИ): нижняя граница годовой > 0.
- **B2-5 (риск ноги):** см. B выше: max просадка ноги ≤ 50% маржи без margin call;
  LIQUIDATED = смерть клетки (артефактов нет, запись в лог — идиом серии A).
- **Правило 1 (carry-аналог, см. C выше):** n ≥ 30 засчитанных settlement на
  агрегате клетки; пустой фолд = провал клетки (flat_fold-флаг).

Клетка = θ-пара × символ (lev первичный = 1, см. A). Письмо: метрики %% и $ рядом
(методология к7-6 переносится дословно).

## B-4. Риски, которые не прячем (обязательные приложения к первому письму)

- (a) basis-дрейф: высокий funding ≈ высокий basis перпа; вход шортом «дорого»,
  выход при нормализации — реальный PnL, который дельта-нейтральная модель обнуляет.
  Митигация после первого вердикта: read-only фетчер premiumIndex/mark-price
  (Binance), отдельная задача НЕ из этой ветки.
- (b) спот-нога assumed: цена спота = index `open`/`close` тех же баров, без
  slip/fee; трение короткой ноги на споте занижено вдвое (в реальности 4 ноги на
  круг) — фиксируется в письме константой «×2 трения» sensitivity-строкой.
- (c) кросс-venue: bars — Bybit, funding — Binance.
- (d) regime-shift: f2 уже показал +0.2%/год — селекция обязана пережить или серия
  умирает честно.
- (e) симуляция без реальных ордеров: риск биржи, капы, лимиты скорости — за рамками;
  оговорка в вердикте.

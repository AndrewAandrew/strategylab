## E2-4 — метод bootstrap (как реализовано, дословно)

Для каждой клетки дневной ряд net склеен по фолдам f1+f2+f3: каждый круг атрибутирован в день его exit_ts из `journal_p.csv` (круг = пара entry→exit, net круга = сумма cash_delta обеих строк; дни без выходов = 0); ряд = 333 дня [1761523200, 1790294400). Moving-block bootstrap: блоки длины 30 дней с circular wrap — на каждой итерации берётся 12 блоков (12×30=360 → обрезка до 333), старт каждого блока ~ uniform на {0,…,322} включительно (randrange(323)), индекс (start+i) mod 333; 1000 повторов, seed=42 (один `random.Random(42)` на весь ряд, повторы идут подряд). Статистика повтора = mean(daily)×365/10000×100 (%/год на капитал $10k, float — так и разрешено для бутстрапа). Нижняя граница = 2.5-й процентиль по 1000 отсортированных статистик (линейная интерполяция, k=0.025×(1000−1)=24.975); верхняя = 97.5-й тем же правилом. PASS (E2-4), если нижняя граница > 0.

Контроль склейки: sum(daily) == pooled net трёх фолдов для всех 18 клеток (Decimal, совпало в пределах 1e-6) — сверка в `meas/grid_E_gates.json` (`daily_sum_check`).

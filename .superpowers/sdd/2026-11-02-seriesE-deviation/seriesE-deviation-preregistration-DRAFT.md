## E-1. Контракт позиции (первичный; оси — после E-0)

**Событие deviation-reversal** на горизонтальной зоне HTF:
- ЗОНА: кластер подтверждённых HTF-пивотов (кастом 1h-баров из `bars_1m`; параметры
  пивота/кластера — ось E-0: w∈{3,5,8}, допуск ∈{0.25%,0.4%,0.6%}, сила ≥3..5 касаний).
  Его слова: зоны/уровни рисует по истории касаний (TradingView), live-посты дают
  зоны шириной ~0.5–2% — диапазон осей E-0 отражает это, не нашу фантазию.
- СОБЫТИЕ long: бар ПРОБИЛ нижнюю границу зоны глубиной ≥ d и ЗАКРЫЛСЯ обратно
  в зоне/над ней; short — зеркально сверху. d — ось E-0 ∈ {0.3%,0.5%,1.0%}.
- ПОДТВЕРЖДЕНИЕ (его «кульминация»/аномальный объём): объём бара ≥ k×медианы объёма
  (k ∈ {1.5,2,2.5} — ось) И wide-spread shape (закрытие у дальнего от пробоя края
  диапазона бара; формулировка — ось E-0).
- РЕЖИМ-ГЕЙТ (его собственная оговорка «в середине боковика сложнее»): ось-кандидат —
  расстояние/сила последнего импульсного legs'а к зоне; конкретный механизм выбирается
  E-0 из (а) без фильтра, (б) только после ≥X% движения за Yч (конец тренда/начало),
  (в) только при «свежести» зоны (последнее касание < Z дней). Пост-probe-выбор
  из его формулировок допустим, потому что все три — прямые цитаты, пороги за froze.
- ИСПОЛНЕНИЕ: решение по закрытию событийного бара; вход `open` следующего бара,
  adverse fill; трение серии A (taker 0.0006 + slip 0.0005/ногу). Выход: V1 = time-box
  24h/48h (два значения — ось); V2 = bracket: стоп за экстремум событийного бара
  (+буфер), тейк на «следующую зону» proxy = фиксированный R-множитель ∈ {1.5,2,3};
  перенос стопа в б/у на +1R (его «двиньте стоп в б/у») — только в V2.
- Плечо 1, маржа не учитывается (экспозиция ≤ капитала; урок D2-5: плечо масштабирует
  только ликвидационные хвосты directional-составляющей).

## E-4. Риски, которые не прячем

- (a) **Режимность — главная:** разведка 180d показывает pooled-плюсы (BTC support-dev
  long +0.3…0.4% медиана; deep resistance-dev short +1.0%) почти целиком из средних
  60 дней; q1/q3 — минусы. Это ровно его «метод работает 1–2–3 месяца, потом стопы».
  E2-3 убивает такие клетки; режим-гейт — единственная честная попытка спасти ось.
- (b) Выбор режима/осей post-probe = threshold shopping; против него — pre-code no-go,
  §8, заморозка до сетки и holdout.
- (c) Mechanical reading его слов — не его руки: зоны он рисует дискреционно; наш
  кластер пивотов — приближение. Досланные владельцем реальные сигналы (5–10 постов)
  могут при freeze сузить оси — аменд с дата-штампом, не молча.
- (d) Объём = суммарный объём 1m→1h/4h перпа Bybit; VSA-дельты (buy/sell volume)
  у нас нет — «кульминация» операционализируется через total-volume+shape. Оговорка
  фиксируется в вердикте.
- (e) 4-часовой таймфрейм его свечного анализа против нашей часовой сетки: ось
  агрегации {1h,4h} — в E-0.
- (f) ликвидность $10k-нотионалов Bybit BTC/ETH вне проверки (как всегда).
